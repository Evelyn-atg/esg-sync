# ESG GT 三维验证（gt_verify）

## 目的
对 100 家公司的 Excel 抽取结果做逐行 Ground Truth 验证，衡量抽取质量与 GT 的一致性。

## 方法（行级三维度）
| 维度 | 字段 | 含义 |
|---|---|---|
| 语义匹配 | matched_semantic | 抽取指标与 GT 指标语义是否对应（yes/no） |
| 单位一致 | unit_consistent | 抽取单位与 GT 单位是否一致（yes/no） |
| 数值匹配 | value_matches | 抽取数值与 GT 数值是否一致（yes/no，含 partial） |

三维全 yes = 该行通过。输出：`gt_verify_out/verify_report.csv`。

## 全量结果（2026-08-06 定稿，100 家 Excel）
- 总行数：16,175
- 三维全 yes：13,839（**85.6%**）
  - 语义匹配 yes：15,175（93.8%）
  - 单位一致 yes：14,985（92.6%）
  - 数值匹配 yes：14,038（86.8%，partial 3 行）
- 排除 00388（港交所）后：15,398 行，三维全 yes **87.8%**

## 00388 港交所：识别误判问题（已解决）

### 问题
旧识别流程（名字模糊匹配）把 **6 份其他公司的报告误判为港交所（00388）**——这些报告封面含交易所上市声明（The Stock Exchange of Hong Kong Limited / HKEX 等字样），被 fuzzy_full / fuzzy_short 匹配到港交所集团的全称/简称：

| PID | 误判方式 | 真实公司（修正后） |
|---|---|---|
| 2025032700732 | fuzzy_short | 00669 TECHTRONIC 创科实业 |
| 2025032804792 | fuzzy_short | 08659 YIK WO 亿和控股 |
| 2025041100201 | fuzzy_full | 03318 CHINA BOTON 中国波顿 |
| 2025042302313 | fuzzy_short | 00698 通达集团 |
| 2025042400063 | fuzzy_short | 08035 骏高控股 |
| 2025042900925 | fuzzy_full | 02190 ZYLOX 归创通桥 |

### 解决过程
1. **修正 manifest**：6 条 code/short/company 按真实公司修正，00388.xlsx 删除，数据按公司拆分归位
2. **识别逻辑升级（防未来）**：
   - 代码优先：优先提取报告自带股票代码（Stock Code / 股份代号）→ 代码对照表精确匹配
   - 交易所黑名单：剔除"上市地点声明"中的机构名（The Stock Exchange of Hong Kong Limited / HKEX 上市上下文），不参与名字匹配
   - 扩展识别页数：前 5 页 → 前 10 页
   - 视觉验证：每份报告渲染封面 1-2 页 → Qwen-VL 识别公司名 + 股票代码 → 交叉验证
3. **结果**：当前 manifest 无 00388 误判残留，100 家 Excel 全部正确命名（代码命名），00388.xlsx 已删除

### 验证统计口径说明
上方统计中 00388 报告自身的验证正确率为 41.8%（777 行，语义不匹配为主，页码定位/指标匹配问题），该数字为 2026-08-06 验证快照；其中识别误判部分已随上述修正消除。

## 验证示例（汇报展示用，取自 verify_report.csv 真实行）

### 示例 A：三维全对（通过 ✅）
| 字段 | 内容 |
|---|---|
| 公司 / 年份 | 00042 / 2023 |
| 指标（code） | E1.1.1 Scope 1 & Scope 2 排放 |
| 单位 | t |
| 记录值 | 2023 = 50 |
| 页面实际 | Atmospheric Emissions - Carbon dioxide（t，2023 = 50） |
| 三维判定 | 语义 ✅ ｜ 单位 ✅ ｜ 数值 ✅ |
| 判定说明 | 页面"大气排放-二氧化碳"指标与记录变量完全对应；单位吨一致；2023 数值 50 完全相符 |

### 示例 B：数值不匹配（❌ 差 1 吨，语义/单位正确）
| 字段 | 内容 |
|---|---|
| 公司 / 年份 | 00042 / 2023 |
| 指标（code） | E2.2.2 非有害废弃物 |
| 单位 | t |
| 记录值 | 2023 = 211 |
| 页面实际 | Non-recyclable waste（t，2023 = 210，2024 = 205） |
| 三维判定 | 语义 ✅ ｜ 单位 ✅ ｜ 数值 ❌ |
| 判定说明 | 页面"不可回收废物"与记录指标对应、单位一致，但 2023 实际为 210 吨，与记录 211 吨存在 1 吨差异 |

### 示例 C：语义不匹配（❌ 指标对应错误）
| 字段 | 内容 |
|---|---|
| 公司 / 年份 | 00042 / 2023 |
| 指标（code） | E2.2.3 废弃物回收率（Total Waste Generated） |
| 单位 | tons |
| 记录值 | 2023 = 212.25 |
| 页面实际 | Non-recyclable waste—Domestic waste（tons，2023 = 210） |
| 三维判定 | 语义 ❌ ｜ 单位 ✅ ｜ 数值 ❌ |
| 判定说明 | 页面指标为"非可回收废物-生活垃圾"，与"废弃物回收率"语义不对应；虽单位一致，但数值 210 与记录 212.25 也不符 |

> 判定逻辑：语义（指标名对应）+ 单位（一致性）+ 数值（逐值比对）**三维全通过**才算该行验证通过；任一维度不通过则记录原因。上面三个示例分别展示"通过"、"仅数值错"、"语义错（连带数值错）"三类典型情况。
